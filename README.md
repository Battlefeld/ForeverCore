# ForeverCore

All-in-One-Addon für **WoW: Forever**: Levelroute, Skillung, Rotation und Item-Vergleich in einem Addon. Schwere
Berechnungen laufen in einem Begleitprogramm auf dem PC (`ForeverCore.exe`).

Stand: Neustart, noch kein lauffähiger Code. Plan und Architektur: [docs/KONZEPT.md](docs/KONZEPT.md).

ForeverCore ist ein inoffizielles Fan-Projekt und steht in keiner Verbindung zu Blizzard Entertainment.
